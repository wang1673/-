# SteerMusic / SteerMusic+ 精读：预测差作为潜变量优化方向

## 基本情况
*SteerMusic: Enhanced Musical Consistency for Zero-shot Text-guided and Personalized Music Editing*，ANU、Sony 等团队；AAAI 2026，按 arXiv 2504.10826v3 阅读。官方 sony/steermusic 公开零样本及个性化编辑脚本。原有简短笔记保留，此处补充公式、信息流及实现核对。

## ① 动机
仅给“换成爵士”会丢失原音乐内容；文本还无法精确描述“用户自己那把吉他的声音”。SteerMusic 用源/目标预测差减少不希望发生的改动；SteerMusic+ 使用个性化扩散模型表达文字难以穷尽的目标概念。

## ② 模块与两种方法
base 复用冻结 AudioLDM2，通过 mel-VAE 编码音频，直接把可优化变量初始化为源 latent。作者写 `g(θ)=θ`，这里 θ 是待编辑潜变量，不是 UNet 参数。`+` 需要另一个已经个性化微调的模型，推理时同时调用 base 和 personalized 模型。

|组件|base|+|
|---|---|---|
|源参考模型|冻结预训练 AudioLDM2|同左|
|目标模型|同一个预训练模型|经过个性化微调的模型|
|更新量|音乐潜变量|音乐潜变量|
|附加约束|DDS|PDS、分布偏移项、PCon|
|整个流程无需训练吗|编辑阶段无需训练模型|个性化准备需要训练，不能笼统称完全 training-free|

## ③ DDS、PDS 与 PCon
正文 §3 的 DDS 给出省略 UNet Jacobian 后的方向：
```text
q = √ᾱ_t x_src + √(1−ᾱ_t)ε
p = √ᾱ_t θ + √(1−ᾱ_t)ε
g_DDS = w(t)[εφ(p,c_tgt,t)−εφ(q,c_src,t)]
θ ← θ−lr·g_DDS
```
同一个时间和噪声非常重要。base 不是按顺序走完 denoising ODE，而是在优化迭代中抽取时间点；SGD 的负梯度步长不可机械解释为 flow 负时间步长。

`+` 将目标预测改为 `εφ′`，源仍为 `εφ`；额外加入 `λw(t)[εφ′(p,c_tgt)−εφ(p,c_tgt)]` 缓和两模型分布偏移。PCon 将同一时间位置的中间特征作为正样本，其他位置作为负样本，推动个性化目标特征与参考对应。论文同时说明可为目标风格允许结构变化，不能把 PCon 称为逐音符硬约束。

源码 `SpecifyGradient` 前向返回占位常数，反向直接注入给定 DDS/PDS 梯度；这个常数的数值不是一个可比较的训练 loss。PCon 分支则要通过模型特征对 latent 反传，模型权重仍冻结。

## ④ 数据、形状与指标
base 使用 ZoME 与 MusicDelta 等音乐数据；ZoME 在不同属性任务中筛选后数量不同，论文分别报告 131/134/100/95，不能合并成每任务相同样本数。MusicDelta 还包含长音频配置。输入字段是原音频、源描述、目标描述；个性化还需要参考音频及概念 token。

代码 latent 为 `[1,8,T,16]`，来自 mel-VAE，`T` 取决于片长；16 是实现中的硬编码频率维。音高评价包含 `1−PCC(CQT)`，相对 Chroma 保留了八度信息，但相关系数本身不能证明复调中每个声部都被保留。目标风格、旋律、主观音乐性应分别报告。

## ⑤ 信息流
```text
音频→log-mel→VAE→latent_ref（固定）
latent（可优化）←latent_ref
源/目标文字编码一次
每次优化：抽 t,ε→两 latent 同噪声→两个噪声预测
    →DDS/PDS 梯度（+ 时另加 shift 与 PCon）→SGD latent
latent→VAE decode→vocoder→音乐
```
没有源轨迹反演，却存在每样本潜变量优化；比较耗时时必须把几百轮优化及所有分支计入。

## ⑥ 数字与源码
示意当前 `θ=2`，目标/源预测 `.7/.2`，权重 `.4`，学习率 `.1`，梯度 `.2`，更新到 `1.98`。下一次抽到不同时间，预测差为 `−.3`，同权重下更新到 `1.992`。预测差可变，因此并非每步都单调提高文本得分。

base `SteerMusic_edit.py` 用 `weight_aug*(1−alphas[t])`，SGD 学习率 `.02`，每 20 步乘 `.9`。默认 `validation_step=400`，循环 `range(validation_step+1)` 共 401 次；保存发生在该轮更新之前，所以最后保存对应 400 次更新，最后第 401 次更新没有再次保存。`+` 保存位置不同，不能把这个结论套到全部脚本。

`steermusic_utils.py::predict_noise` 支持指定同一个 `t,noise`；`SpecifyGradient.backward` 是真实梯度入口；`SteerMusic_personalized.py` 是 PDS/shift/PCon 整合入口。完整源码注释和行号对应见 [代码原文对应](代码原文对应.md)。

## 边界与研究价值
“无需反演”和“无需优化”是两条独立属性。base 是前者，不是后者。对音乐研究，可将 DDS 作为结构保留的优化基线，但应同时公布迭代数、目标 CFG 与耗时，避免拿 400 次优化和 28 步 flow 方法只比输出指标。
