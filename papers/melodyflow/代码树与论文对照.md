> 范围：facebook/MelodyFlow Hugging Face Space 的公开推理/demo 源码。论文 arXiv:2407.03648v2。

## 论文模块到源码的逐项映射

| 论文内容 | 对应源码 | 读代码时关注什么 |
|---|---|---|
| §2.1 连续 latent 音频 codec | `models/encodec.py`；`models/melodyflow.py` 的 `encode_audio` 与解码路径 | 波形如何压成低帧率连续表示，以及 latent 如何回到波形。论文 codec 由 EnCodec 衍生，结合 DAC Snake 激活、分频带 STFT 判别器和 KL 瓶颈。 |
| §2.2 条件 Flow Matching | `models/flow.py` 的 `FlowModel.forward` | 输入状态和时间，经投影、时间嵌入及 Transformer 后输出速度 (v_\theta(z_t,t,c))，不是音频类别或离散 token。 |
| §3.1 T5 cross-attention DiT | `modules/conditioners.py`、`modules/transformer.py`，以及 `models/flow.py` 的 conditioning 路径 | 文本先转成条件表征，再由 DiT 注意力层读取；flow 时间也注入主干。论文模型还报告 U 形 skip connections 和 L 形注意力 mask。 |
| §2.2 生成 ODE | `models/flow.py` 的 `generate` / ODE 更新路径 | 从噪声 (t=0) 正向积分到 (1)；论文生成使用 midpoint solver。 |
| §2.3–2.4 源音频反演与编辑 | `models/melodyflow.py` 的 `edit`；`models/flow.py` 的反向积分和正向积分 | wrapper 先以源条件从 (1) 走到 (T_{edit})，再以目标条件走到 (1)，最后 decode。 |
| §2.4 ReNoise 风格轨迹校正 / patch-KL | `models/flow.py` 反演正则化循环；`utils/renoise.py` | 每个反演步对多个候选更新估计可逆性，并用 patch-KL 调整预测速度统计特征。论文报告 (K=4)、λKL=0.2。 |
| §3 推理界面 | `demos/melodyflow_app.py`、`demos/melodyflow_demo.ipynb` | 查看用户实际提交的源音频、编辑提示、solver 和时长如何进入模型 API。 |
| 预训练模型信息 | `docs/MELODYFLOW.md` | 检查 medium/small 模型的采样率、声道、帧率、最长生成时长及下载标识。 |

## 关键调用链：编辑一段源音频

1. `MelodyFlow.get_pretrained(...)` 通过 loader 载入音频 codec 和 flow DiT；编辑参数由 wrapper 的默认配置或调用者覆写。
2. `encode_audio(audio)` 将波形编码为连续 latent (x_{src})。
3. `edit_audio(...)` / `edit(...)` 将 latent、源描述和目标描述交给 FlowModel。先用源条件反向积分，得到 (z_{T_{edit}})。
4. 反演循环内，FlowModel 在 (t-\Delta t) 处更新候选 latent；正则化分支构造训练路径上的参考 latent，比较 patch 速度统计并校正。多个候选按权重合并。
5. 以目标文字为条件，从 (T_{edit}) 正向求解 ODE 到 (1)，得到编辑 latent。
6. codec decoder 把 latent 还原为音频波形。

**变量命名提醒：** `melodyflow.py` 内的成员变量 `lm` 是兼容 AudioCraft 基类/加载器命名的模型对象；MelodyFlow 的实际主干是连续 latent FlowModel。不要把它误读成 `models/lm.py` 中离散 token 的自回归语言模型。

## 复现时易混淆的设置

- 论文编辑实验：反演 25 步，(K=4)，patch-KL 权重 0.2；论文实验 CFG 为 4.0。相关细节见论文 §3.2。
- 官方 wrapper 默认：Euler、25 步、regularization 开启、迭代数 4、保留后两次迭代、权重 0.2，(T_{edit}=0.0)。论文目标中间时间与 API 默认值需要区分，复现实验时应显式设置。
- Flow Matching 方向：训练插值 (z_t=t x+(1-t)\epsilon)，数据端是 (t=1)、噪声端是 (t=0)。生成从噪声正向走；编辑反演从源 latent 反向走。
- 官方作者说明没有计划发布训练代码；因此上述目录不能提供完整训练复现流水线。论文内部数据集和训练目标的细节应以论文/附录为准。
- 专用 MelodyFlow Space 与 AudioCraft GitHub 默认分支不是同一个可直接逐文件比较的快照；引用源码时请保留 Space 链接和版本。
