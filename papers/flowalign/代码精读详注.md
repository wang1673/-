## 读懂 FlowAlign 比 FlowEdit 多出的那一项

此公开实现以 SD3 为速度模型，`run_edit.py` 选择 `flowalign` 编辑类。源图经 VAE 编码为固定 `zsrc`；每步抽 ε，构造 `qt=(1−σ)zsrc+σε` 和 `pt=xt+qt−zsrc`。在同一 `pt` 上查询目标速度 `vpc`、源速度 `vpn`，组合 `vp=vpn+cfg_scale(vpc−vpn)`；在 `qt` 上查询源速度 `vq`。

```text
xt_next = xt + (σ_next−σ)(vp−vq)
             + 0.01(qt−σ·vq−pt+σ·vp)
```

前一项是差分速度的 Euler 更新；后一项是代码固定系数的轨迹对齐修正。它不是新的网络，也不是 VAE 解码步骤。`cfg_scale` 在这里以 `pt` 的**源条件**作基线，不能误读为传统空提示 CFG。`sd3_sampler.py` 负责 CLIP/T5 条件布局、VAE 缩放及 transformer 查询，编辑算法集中在 `sd3_edit.py::SD3FlowAlign.sample`。

**数字例子（教学示意）**：`zsrc=xt=2, σ=.8, ε=0` 时 `qt=pt=.4`。若 `vp=3,vq=1,σ_next=.7`，速度差项给 `−.2`；对齐项此刻为 `.01×(.4−.8×1−.4+.8×3)=.016`，故下一状态 `1.816`。随后 `xt` 改变，`pt` 与 `qt` 分离，对齐项更有意义。

这里的方法对象是图像 latent；把轨迹正则搬到音乐 `[B,D,T]` 前，需重新定义音乐结构距离并检查时间轴长度与 codec 误差。

### `diffusion/editing/sd3_edit.py`

[原始源码](code-used/diffusion/editing/sd3_edit.py) · [中文注释版](annotated/diffusion/editing/sd3_edit.py)

- [L201](code-used/diffusion/editing/sd3_edit.py#L201) `self.scheduler.set_timesteps(NFE, device=self.transformer.device)`：NFE 配置离散时间表；后面使用 t/训练步数得到连续噪声权重 sigma。
- [L205](code-used/diffusion/editing/sd3_edit.py#L205) `with torch.no_grad():`：源图像仅 VAE 编码一次并固定 zsrc；后续每步采样都从它解析构造 q_t。
- [L210](code-used/diffusion/editing/sd3_edit.py#L210) `for i, t in enumerate(pbar):`：每步生成一个共享 ε，计算源查询 q_t 和含编辑位移的目标查询 p_t。
- [L216](code-used/diffusion/editing/sd3_edit.py#L216) `qt = (1-sigma)*zsrc + sigma*eps`：q_t=(1−σ)zsrc+σε 是源条件评估位置，不是一次反演所得的真实源轨迹。
- [L217](code-used/diffusion/editing/sd3_edit.py#L217) `pt = xt + qt - zsrc`：p_t=xt+q_t−zsrc 是目标评估位置；完整保留当前编辑位移。
- [L220](code-used/diffusion/editing/sd3_edit.py#L220) `vpc = self.predict_vector(pt, timestep, tgt_prompt_emb[0], tgt_prompt_emb[1])`：vpc 是 p_t 的目标条件速度，vpn 是同一 p_t 的源条件速度。
- [L222](code-used/diffusion/editing/sd3_edit.py#L222) `vp = vpn + cfg_scale * (vpc - vpn)`：vp=vpn+cfg_scale(vpc−vpn)；这里以源条件作引导基线，并非空 prompt CFG。
- [L223](code-used/diffusion/editing/sd3_edit.py#L223) `vqn = self.predict_vector(qt, timestep, src_prompt_emb[0], src_prompt_emb[1])`：vqn 是 q_t 上的源条件速度，随后从目标路径速度 vp 中减去。
- [L226](code-used/diffusion/editing/sd3_edit.py#L226) `xt = xt + (sigma_next-sigma) * (vp-vq) + 0.01 * (qt - sigma*vq - pt + sigma*vp)`：前项是 FlowEdit 式速度差 Euler；0.01·(q−σvq−p+σvp) 为论文轨迹对齐修正，系数是代码常量。
