## 核心变量与论文的 Diffusion Prediction Contrast

这份实现先把音频映到 mel，再通过所选 TANGO/AudioLDM wrapper 的 VAE 得到 `x_src`。`zt_edit` 从 `x_src` 复制。与 FlowEdit 的目标查询 `y+q−x_src` 不同，此处对固定源与当前编辑结果分别用**同一份扩散噪声**解析加噪，并让 DDIM 调度器分别算出反向位移，再求位移差。

```text
q_t = √ᾱ_t·x_src + √(1−ᾱ_t)·ε
p_t = √ᾱ_t·y_t   + √(1−ᾱ_t)·ε
δ_src = DDIM(q_t, ε_src, t)−q_t
δ_tgt = DDIM(p_t, ε_tgt, t)−p_t
y_next = y_t+δ_tgt−δ_src
```

程序入口 `daedit` 读音频、编码 latent、缓存文字条件；`text2image_daedit_theory` 逐步调用 `ldm_step_noise_2`，批量获得目标与源的 CFG 预测；最后用 wrapper 的 VAE/vocoder 输出 16 kHz 音频。`fix_noise` 决定一条轨迹复用噪声还是每步重新抽；源和目标在**同一步**始终共用噪声。

**数字例子（教学示意）**：`x_src=y=2, ᾱ=.64, ε=1`，两个查询均为 `2.2`。假设调度器给目标候选 `1.9`、源候选 `2.1`，则两个位移为 `−.3` 与 `−.1`，编辑状态变成 `2−.3−(−.1)=1.8`。这些候选是任意示意数，非论文实验输出。

**代码与论文需分开看**：`models.py` 兼容不同音频 backbone，输入声学表示、文字分支、调度器可能不同。命令行定义的 `n_avg` 在当前 `daedit → text2image_daedit_theory` 调用链中未传入，不应据此宣称本路径对多个噪声样本求均值。

### `code/models.py`

[原始源码](code-used/code/models.py) · [中文注释版](annotated/code/models.py)

- [L18](code-used/code/models.py#L18) `class PipelineWrapper(torch.nn.Module):`：统一 wrapper 只抽象模型接口；Tango/AudioLDM 系列的文本编码、VAE 和 scheduler 细节仍各异。
- [L25](code-used/code/models.py#L25) `def get_sigma(self, timestep) -> float:`：σ_t=√(1/ᾱ_t−1) 是扩散噪声强度的另一种参数化；不要把它当作 FlowEdit 的线性插值 t。
- [L291](code-used/code/models.py#L291) `class TangoWrapper(PipelineWrapper):`：Tango 的 wrapper 从模型配置恢复 STFT、文本编码器、VAE 和 scheduler，决定输入 latent 的真实形状。
- [L334](code-used/code/models.py#L334) `def vae_encode(self, x: torch.Tensor):`：Tango VAE 编码进入音频潜变量；这一步的 scale 应与对应 checkpoint 的解码保持一致。
- [L406](code-used/code/models.py#L406) `class Tango2Wrapper(PipelineWrapper):`：Tango2 路径通过独立模块加载，不能直接套用 Tango 的文本嵌入字段。
- [L494](code-used/code/models.py#L494) `class AudioLDMWrapper(PipelineWrapper):`：AudioLDM 包装层使用另一套音频前处理与条件结构；相同编辑更新不意味着 backbone 完全相同。
- [L572](code-used/code/models.py#L572) `class AudioLDM2Wrapper(PipelineWrapper):`：AudioLDM2 需要多路文本/语言模型条件；主编辑循环的 batch 拼接要与此 wrapper 返回结构对齐。
- [L635](code-used/code/models.py#L635) `def encode_text(self, prompts: List[str]):`：这里构造 AudioLDM2 文本条件；包含生成文本嵌入与 mask，不能简化成一个句向量。
- [L729](code-used/code/models.py#L729) `def unet_forward(self,`：AudioLDM2 的 UNet 前向负责把拼接 batch 的目标/源条件映射成噪声预测。
- [L1030](code-used/code/models.py#L1030) `def load_model(model_id, device, num_diffusion_steps, double_precision=False):`：根据 model_id 选择 wrapper；复现实验必须同时记录 checkpoint 与 scheduler 类型。
