## 先抓住运行时状态

论文 §4 把两条精确反演/生成轨迹改写为速度差；§5 用解析源加噪替代真实反演轨迹。`x_src` 是一次 VAE 编码后固定的源 latent，`zt_edit` 是正在累积语义变化的干净编辑状态。每步的 `zt_src` 和 `zt_tar` 是查询速度场的两个带噪位置，它们不作为下一步编辑状态直接保存。SD3 的 `t=1` 靠噪声、`t=0` 靠图像，故 Euler 的 `t_next-t_i` 为负。

```text
q_t = (1−t)x_src+tε
p_t = y_t+q_t−x_src
Δv_t = mean_k[v_target(p_t,t)−v_source(q_t,t)]
y_next = y_t+(t_next−t)Δv_t
```

按程序走：`run_script.py` 加载 SD3/FLUX 与任务 YAML，VAE 编码并缩放源图；`FlowEditSD3`/`FlowEditFLUX` 编码两段文字，复制源 latent 初始化 `y`，每个时间点共享随机噪声构造 `q,p`，做两条件速度查询和 Euler 更新，最后逆缩放并 VAE 解码。SD3 的外部 CFG 批次次序与 FLUX 内部 guidance 接口不同；比较两模型时不要直接比较数值。

**数字例子（教学示意）**：`x_src=y=2, ε=0, t=.8`，则 `q=.4,p=.4`。若目标速度为 `−1`、源速度为 `1`，下个时间为 `.7`，则 `y_next=2+(.7−.8)×(−2)=2.2`。第二步重新采噪声时，`y` 保持 `2.2`，`q,p` 都重新构造。

**读代码要停一下的地方**：`n_max` 跳过早期步，`n_min>0` 将末段改为普通目标采样。SD3 这条末段路径在原代码使用未在该函数定义的 `noise_pred_tar`（原始 L223）；默认 `n_min=0` 不走此分支。下方注释保留原语句，只标出风险。论文无全局最优传输保证。

### `FlowEdit_utils.py`

[原始源码](code-used/FlowEdit_utils.py) · [中文注释版](annotated/FlowEdit_utils.py)

- [L75](code-used/FlowEdit_utils.py#L75) `if pipe.do_classifier_free_guidance:`：SD3 的 batch 次序为源无条件、源文字、目标无条件、目标文字；下面的 chunk(4) 必须与这个顺序一致。
- [L127](code-used/FlowEdit_utils.py#L127) `timesteps, T_steps = retrieve_timesteps(scheduler, T_steps, device, timesteps=None)`：取实际 scheduler 时间表；T_steps 是离散查询数，后面的 t/1000 才是此实现使用的连续时间。
- [L149](code-used/FlowEdit_utils.py#L149) `pipe._guidance_scale = tar_guidance_scale`：编码目标描述前暂时切换 guidance，源/目标 CFG 可独立调节；这里仍使用同一套冻结模型。
- [L165](code-used/FlowEdit_utils.py#L165) `src_tar_prompt_embeds = torch.cat([src_negative_prompt_embeds, src_prompt_embeds, tar_negative_prompt_embeds, ta…`：两个文字条件和两个无条件嵌入按速度查询 batch 次序拼接，不能把源和目标 prompt 交换。
- [L169](code-used/FlowEdit_utils.py#L169) `zt_edit = x_src.clone()`：编辑变量 y₁ 初始化为原图 latent；它是累积编辑位移的状态，不是需要反演出的噪声端点。
- [L173](code-used/FlowEdit_utils.py#L173) `if T_steps - i > n_max:`：n_max 让最早的高噪声时间点跳过更新；改变它会同时影响编辑强度和源结构保留。
- [L176](code-used/FlowEdit_utils.py#L176) `t_i = t/1000`：SD3 的整数时间戳缩放到 [0,1]；Euler 更新用的是相邻连续时间之差。
- [L182](code-used/FlowEdit_utils.py#L182) `if T_steps - i > n_min:`：只有剩余步数大于 n_min 时执行源/目标速度差 ODE；末 n_min 步切换目标单流采样。
- [L188](code-used/FlowEdit_utils.py#L188) `fwd_noise = torch.randn_like(x_src).to(x_src.device)`：每个时间点重新取同形高斯 ε；源与目标查询共享这一份 ε，n_avg 会重复此配对并平均。
- [L190](code-used/FlowEdit_utils.py#L190) `zt_src = (1-t_i)*x_src + (t_i)*fwd_noise`：q_t=(1−t)x_src+tε 是源样本的解析加噪状态；x_src 在全部迭代中固定。
- [L192](code-used/FlowEdit_utils.py#L192) `zt_tar = zt_edit + zt_src - x_src`：p_t=y_t+q_t−x_src；把当前编辑位移 y_t−x_src 加到同噪声源查询上，是论文直接 ODE 的关键耦合。
- [L194](code-used/FlowEdit_utils.py#L194) `src_tar_latent_model_input = torch.cat([zt_src, zt_src, zt_tar, zt_tar]) if pipe.do_classifier_free_guidance els…`：四个 latent 的 batch 排序与上面的条件嵌入排序配对；此处非 CFG 分支的容器类型也应单独核查。
- [L198](code-used/FlowEdit_utils.py#L198) `V_delta_avg += (1/n_avg) * (Vt_tar - Vt_src) # - (hfg-1)*( x_src))`：Δv=平均(v_target(p_t)−v_source(q_t))；平均的是速度差，不是先平均两个独立图像。
- [L203](code-used/FlowEdit_utils.py#L203) `zt_edit = zt_edit + (t_im1 - t_i) * V_delta_avg`：Euler 步：y_{i+1}=y_i+(t_{i+1}−t_i)Δv；时间向数据端下降，所以增量通常为负。
- [L212](code-used/FlowEdit_utils.py#L212) `xt_src = scale_noise(scheduler, x_src, t, noise=fwd_noise)`：切换普通采样时只在边界重新加噪一次，然后以目标条件继续积分。
- [L221](code-used/FlowEdit_utils.py#L221) `prev_sample = xt_tar + (t_im1 - t_i) * (Vt_tar)`：目标单流末段的 Euler 候选；原码下一行引用本函数未定义的 noise_pred_tar，n_min>0 需先修复。
- [L263](code-used/FlowEdit_utils.py#L263) `sigmas = np.linspace(1.0, 1 / T_steps, T_steps)`：FLUX 自建 sigma 网格并交给 scheduler；与 SD3 的 t/1000 约定不能混用。
- [L310](code-used/FlowEdit_utils.py#L310) `if pipe.transformer.config.guidance_embeds:`：FLUX 使用模型内部 guidance embedding，此值不能直接当作 SD3 外部四分支 CFG 系数。
- [L328](code-used/FlowEdit_utils.py#L328) `t_i = scheduler.sigmas[scheduler.step_index]`：真正用于 FLUX 数值更新的是 scheduler.sigmas[step_index]，而非仅看循环变量 t 的字面值。
- [L344](code-used/FlowEdit_utils.py#L344) `zt_src = (1-t_i)*x_src_packed + (t_i)*fwd_noise`：FLUX 的源查询也用共享噪声 q_t=(1−sigma)x_src+sigmaε，latent 已打包成 token。
- [L346](code-used/FlowEdit_utils.py#L346) `zt_tar = zt_edit + zt_src - x_src_packed`：目标查询加上完整编辑位移；不是把 y_t 再做一次普通前向加噪。
- [L367](code-used/FlowEdit_utils.py#L367) `V_delta_avg += (1/n_avg) * (Vt_tar - Vt_src) # - (hfg-1)*( x_src))`：多个随机耦合得到的速度差求平均；n_avg 增大增加模型查询与计算成本。
- [L372](code-used/FlowEdit_utils.py#L372) `zt_edit = zt_edit + (t_im1 - t_i) * V_delta_avg`：打包 latent 上直接做差分 Euler 步；t_next−t 由 sigma 网格决定。
- [L400](code-used/FlowEdit_utils.py#L400) `out = zt_edit if n_min == 0 else xt_tar`：返回前将 FLUX token latent 解包给 VAE；输出仍是图像 latent，而不是波形或音乐 latent。
